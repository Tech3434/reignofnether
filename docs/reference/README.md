# reference — что удалено и как это вернуть

Каталог инвентаризует контент, снесённый на этапе D (решение 2 плана: удалённый контент
сохраняется как документация, а не остаётся в дереве). Здесь — списки файлов и краткое описание
роли каждой подсистемы. **Как собирать новое** — в `_GUIDES/`.

Любой файл восстанавливается из истории:

```
git show 5079004e:src/main/java/com/solegendary/reignofnether/<путь> > <файл>
```

`5079004e` — состояние дерева на момент составления плана (до удаления контента).

| Файл | Что описывает |
|---|---|
| [`units.md`](units.md) | 113 классов юнитов трёх фракций; анатомия класса юнита |
| [`buildings.md`](buildings.md) | 68 классов строений; `placements/`, пять аддонов |
| [`abilities.md`](abilities.md) | 93 способности, геройские и обычные |
| [`production.md`](production.md) | очередь и стоимость — **каркас**, не удалялся |
| [`research.md`](research.md) | 51 исследование; гейт способностей был только клиентским |
| [`economy.md`](economy.md) | источники ресурсов, стоимости, население |
| [`waves.md`](waves.md) | планировщик волн survival как пример «спавнить по таймеру» |
| [`items.md`](items.md) | предметный слой юнитов; `UnitInventory` остался |
| [`assets.md`](assets.md) | текстуры, модели, звуки, переводы контента |
| [`enchantments.md`](enchantments.md) | 7 чар датапака |
| [`fog-of-war.md`](fog-of-war.md) | туман войны — почему удалён целиком |
| [`faction.md`](faction.md) | `Faction` — почему не воссоздавать как `FactionDefinition` |
| [`match-setup.md`](match-setup.md) | стартовые позиции, сценарий, обучение, карта |

Точный статус работ и пройденные гейты — в [`../STATUS.md`](../STATUS.md).
