эти документы.

## Быстрый старт

```bash
cd ___temp
set JAVA_HOME=C:\Program Files\Java\jdk-21
gradlew.bat compileJava      # гейт 1: компиляция
gradlew.bat validateMixins   # гейт 2: применение миксинов
gradlew.bat runData          # гейт 3: генерация данных
gradlew.bat runServer        # гейт 4: выделенный сервер (завершается сам)
gradlew.bat runClient        # гейт 5: клиент (не завершается сам, останавливать вручную)
```

Ни один гейт не проверяет геометрию на экране и не проверяет зависание при выходе из мира —
это только ручной прогон в игре.

## Правила работы с кодом этого мода

1. **Сверяться с апстримом.** `git show 918672b7:<путь>` — база 1.20.1; расхождение с ней
   часто и есть баг, но не всегда: часть отличий намеренная (см. §10 `AGENT_HANDOFF.md`).
2. **Симптом «не зависит от камеры» означает испорченные данные**, а не матрицы.
3. **Идентичные числа пробы между прогонами** означают, что состояние приходит из мира или
   конфигурации, а не накапливается в игре.
4. **`jstack` на зависшем процессе** быстрее любого чтения кода: сразу видно дедлок это или
   спин, и точную строку ванильного цикла.
5. **`javap` по `build/moddev/artifacts/neoforge-21.1.250-merged.jar`** — источник истины по
   сигнатурам 1.21.1; исходники ванилы распаковываются из
   `build/moddev/artifacts/neoforge-21.1.250-sources.jar` (в отличие от старых версий, там
   **есть** и `net/minecraft/**`).
6. Никаких «автофиксов» при переезде версии, молча меняющих числа: удалённый конструктор или
   метод заменять эквивалентом с проверенной семантикой, а не ближайшим по сигнатуре.
