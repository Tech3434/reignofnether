## Порядок при добавлении контента

1. **Атрибуты и эффекты** — если нужны новые, сначала они (`registrars/AttributeRegistrar`,
   `registrars/MobEffectRegistrar`).
2. **Юнит** — `02_unit.md`. Без юнита нельзя сделать производство от него.
3. **Способности** — `04_ability.md`, затем `UnitAction`.
4. **Производственный предмет** — `06_production.md`.
5. **Здание** — `03_building.md`, и только потом добавлять в него производство.
6. **Исследование** — `07_research.md`, если способность должна быть за исследованием.
7. **Герой** — `05_hero.md`, если юнит герой.
8. **Ассеты и переводы** — `09_assets.md`.

Фракция целиком, включая стартовые позиции и роли — `01_faction.md`.

## Что не работает без правок в другом месте

| Место | Что требует |
|---|---|
| JSON-здание без `flags.canAcceptResources` | рабочие не сдадут ресурсы (нужно столице) |
| JSON-здание без `production`/`researches` | очередь пуста, кнопок нет |
| JSON-юнит `role: ranged` без `equipment` | лучник не удержит лук, цель не активируется |
| Способности из JSON (`abilities`) | `AbilityTypes.register(...)` пуст — тип нужно зарегистрировать |
| Аддоны из JSON (`addons`) | тип должен быть в `AddonTypes` (движковые — в `Addons.init`) |
